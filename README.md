# Калькулятор модулей Siemens — ASUTP TEAM

Онлайн-подбор модулей SIMATIC S7-300 / S7-1200 / S7-1500 и периферии ET 200 по количеству сигналов. Один самодостаточный файл `index.html` — без бэкенда, весь расчёт на клиенте.

## Как обновить цены

Все цены в одном месте — секция `ДАННЫЕ` в начале `<script>` в `index.html`:

- `PRICES_DATE` — строка с датой актуальности (показывается в дисклеймере и PDF);
- у каждой позиции `reg('6ES7...', 'название', 65000)` — третий аргумент и есть цена в рублях.

Вилка бюджета считается автоматически: −15 % / +20 % от суммы базовых цен, с округлением до «красивых» значений. Коэффициенты — в функции `render()` (`res.total*0.85` и `res.total*1.2`).

## Как задеплоить

Файл статический — подходит любой хостинг:

1. **GitHub Pages**: репозиторий → положить `index.html` → Settings → Pages → deploy from branch. Бесплатный HTTPS.
2. **asutp.team**: положить файл на хостинг сайта, например как `calc/index.html` → страница `asutp.team/calc`.

## Telegram Mini App (когда появится бот)

1. В @BotFather: `/newbot` (если бота ещё нет) → `/newapp` → указать HTTPS-URL страницы.
2. В `index.html` перед `</body>` добавить:
   `<script src="https://telegram.org/js/telegram-web-app.js"></script>`
   — страница продолжит работать и в обычном браузере, и в Telegram. Место помечено комментарием «Telegram Mini App» в конце скрипта.

## Что зашито в логику (кратко)

- Правила компоновки: 8 SM на стойку S7-300 (до 4 стоек через IM 360/361), лимиты SM у CPU 1212C/1214C/1215C (2/8/8), 30 модулей у S7-1500, вместимость станций: ET 200M — 8 (DP) / 12 (PN), ET 200S — 63, ET 200SP — 32.
- Подбор CPU автоматом (борт-каналы компактных CPU идут в зачёт; HSC 1200-й занимают борт-входы), ручная смена — селектом. Станция и сеть периферии подтягиваются под серию (300 → ET 200M + PROFIBUS, 1200/1500 → ET 200SP + PROFINET), меняются вручную.
- Списки CPU: S7-300 — 12 моделей (312…319-3, компактники с бортом и фронтштекерами) + IM 151-7 CPU / IM 151-8 PN/DP CPU (контроллеры в станции ET 200S); S7-1200 — 1211C…1217C во всех исполнениях (DC/DC/DC, DC/DC/Rly, AC/DC/Rly); S7-1500 — 1511…1518, компактники 1511C/1512C (штекеры борта в комплекте) + CPU 1510SP/1512SP (контроллеры в станции ET 200SP, до 64 модулей). Автоподбор предлагает только ходовые ступени; редкие модели — ручной выбор. Лимиты зашиты: CPU 312/312C — одна стойка, 1211C — без модулей расширения, 1516-3/1517/1518 — PROFIBUS без CM.
- Устройства связи: RS-232 (CP 341 / CM 1241 / CM PtP), RS-485/422 (те же семейства), PROFIBUS DP-устройства (мастер CM 1243-5 / CM 1542-5 / DP-порт CPU + разъёмы). CP и CM PtP занимают слоты на рейке, CM 1241 — до 3 шт. слева от CPU.
- Режим «Контроллер уже есть» (модернизации): CPU, карта памяти, БП и центральная рейка не попадают в спецификацию, модель существующего CPU задаётся селектом.
- Обвязка автоматом: фронтштекеры (включая 2×40-пол. для борта CPU 313C), профильные шины по ширине набора, БП по числу модулей, карты памяти, IM-пары с кабелями, BaseUnit светлые/тёмные, TM/PM-E для ET 200S, разъёмы PROFIBUS по узлам.
- Критерий подбора — минимум модулей (плотные первыми, остаток — минимально достаточным модулем; у 1200-й — комбо SM 1223 и сигнальные платы SB для мелких остатков).
- Артикулы сверены с официальными источниками Siemens (support.industry.siemens.com, SiePortal) в августе 2026.

## Ограничения (v1)

- Без F-сигналов (safety), без HART, без панелей оператора. Модули связи считаются только в центральном шкафу (у CPU).
- Кабели PROFIBUS/PROFINET метражом не считаются (длины трасс калькулятор не знает).
- Нагрузка полевых цепей 24 В в подборе БП не учитывается — только модули.
- Цены ориентировочные (параллельный импорт, разброс закрыт вилкой).
